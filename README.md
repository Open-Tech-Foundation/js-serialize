# Serialize

***Type-preserving JSON for JavaScript: readable on the wire, safe on untrusted input***

[npm](https://www.npmjs.com/package/@opentf/serialize) | [JSR](https://jsr.io/@opentf/serialize) | [Wire format](#wire-format)

</div>

<div align="right">

*An [Open Tech Foundation](https://opentechf.org/) project*

> `JSON.stringify` turns a `Date` into a string, a `Map` into `{}` and a `BigInt`
> into an exception. `@opentf/serialize` keeps them — plus typed arrays, `Temporal`,
> `undefined`, `NaN`/`-0` and circular references — while plain data stays plain JSON.

```ts
import { parse, stringify } from "@opentf/serialize";

const text = stringify({ at: new Date(0), tags: new Set(["a"]), big: 10n });
// {"v":{"at":"@1","tags":"@2","big":"@3"},"$refs":{"1":{"_t":"Date","_v":"1970-01-01T00:00:00.000Z"},…}}

const value = parse(text, { maxLength: 1_000_000, maxDepth: 64 });
value.at.getFullYear(); // a live Date again
```

> [!NOTE]
> **Pre-1.0.** The API can change between minor versions. The wire format is the one
> [obj-diff 0.18](https://obj-diff.opentechf.org/docs/serialization) writes, byte for byte.

## Why Serialize

| Need | How Serialize meets it |
| --- | --- |
| 👀 **Readable on the wire** | Plain data stays as it is; only special values become `"@n"` tokens, so a network panel still shows your object. |
| 🔒 **Safe on hostile input** | `__proto__` keys become own properties, never prototypes; every `$refs` entry is shape-checked; malformed input is an error, never `undefined`. |
| 🚧 **Bounded work** | Opt-in `maxLength` and `maxDepth` stop oversized or deeply nested bodies before they cost a stack overflow. |
| 🏷️ **Errors you can branch on** | One `SerializeError` class with a `code` — map `INPUT_TOO_LARGE` to 413 and the rest to 400. |
| 📦 **No dependencies** | One small ESM + CJS package with its own `.d.ts`; runs anywhere `JSON` does. |

## Compared with other libraries

| | **@opentf/serialize** | superjson | devalue | seroval (JSON mode) | @ungap/structured-clone |
| --- | --- | --- | --- | --- | --- |
| **Wire shape** | Your JSON + `$refs` table | Your JSON + `meta` paths | Flattened slot array | Node tree | Flattened records |
| **Plain data stays readable** | Yes | Yes | No | No | No |
| **Own `__proto__` key** | Kept as own key | Rejected (throws) | Rejected (throws) | Kept as own key | Kept as own key |
| **Wrong-shape input** | Throws | Returns `undefined` | Throws | Throws | Throws |
| **Depth limit** | `maxDepth` (opt-in) | None | None | `depthLimit` (1000) | None |
| **Input size limit** | `maxLength` (opt-in) | None | None | None | None |
| **Cycles through `Map`/`Set`** | Yes | Yes | Yes | Yes | Yes |
| **Custom classes** | No | `registerClass` | reducers / revivers | Plugins | No |
| **Runtime dependencies** | 0 | 1 | 0 | 0 | 0 |

Serialize trades a little speed and size for a format you can read and a parser you can
point at a request body. When you need custom classes, use seroval or devalue.

## Supported values

| Kind | Values |
| --- | --- |
| **Primitives** | `string`, `number`, `boolean`, `null`, `undefined`, `bigint`, `NaN`, `±Infinity`, `-0` |
| **Built-ins** | `Date` (incl. invalid), `RegExp`, `URL`, `Map`, `Set`, boxed `Number` / `String` / `Boolean` |
| **Errors** | `Error` and its standard subclasses, with `name`, `message` and own properties |
| **Binary** | Every typed array, `ArrayBuffer`, `DataView` — byte-exact, as base64 |
| **Temporal** | Any `Temporal.*` value; decoding needs `globalThis.Temporal` |
| **Graphs** | Cycles and shared identity through objects, arrays, `Map`, `Set` and `Error`; any value used twice decodes to one object |
| **Sparse arrays** | Holes stay holes, distinct from `undefined` and `null` |

Symbols, functions and class instances throw.

## Wire format

`stringify` writes an envelope `{"v": <value>, "$refs"?: {...}}`:

| Piece | Rule |
| --- | --- |
| **Plain data** | Written as ordinary JSON. User keys named `_t` / `_v` are just data. |
| **Special values** | Replaced by a token `"@n"`; `$refs["n"]` holds `{ "_t": <type>, "_v": <payload> }`. |
| **Strings starting with `@`** | Escaped with one more `@`, so they never read as tokens. |
| **Shared or cyclic values** | Written once in `$refs` (plain containers as an `obj` / `arr` entry) and referenced by token everywhere; single-use plain containers stay inline. |
| **Array holes** | Every hole is a token for one shared `{"_t":"hole"}` entry. |
| **No special values** | No `$refs` key at all: `{"v":{"a":1}}`. |

## Untrusted input

```ts
import { parse, SerializeError } from "@opentf/serialize";

try {
  return parse(body, { maxLength: 1_000_000, maxDepth: 64 });
} catch (err) {
  if (err instanceof SerializeError) return new Response(null, { status: err.code === "INPUT_TOO_LARGE" ? 413 : 400 });
  throw err;
}
```

| Option | Effect | Default |
| --- | --- | --- |
| `maxLength` | Longest input, in UTF-16 code units (`text.length`), checked before `JSON.parse` | Unlimited |
| `maxDepth` | Deepest container nesting — arrays, objects, `Map`, `Set`, `Error` props, hoisted ones included. `[[1]]` is 2 | Unlimited |

`stringify(value, { maxDepth })` takes the same depth limit.

## Errors

Every failure is a `SerializeError` (a subclass of `Error`) whose `code` is one of:

| `code` | Meaning |
| --- | --- |
| `INVALID_INPUT` | `parse` was given something other than a string |
| `INVALID_JSON` | The text is not JSON (`cause` holds the `SyntaxError`) |
| `INPUT_TOO_LARGE` | Longer than `maxLength` |
| `INVALID_ENVELOPE` | Not `{"v": ...}`, or `$refs` is not an object |
| `MAX_DEPTH` | Nests deeper than `maxDepth` |
| `MISSING_REF` | A `"@n"` token with no `$refs` entry |
| `UNKNOWN_TYPE` | An unrecognised `_t` tag |
| `INVALID_PAYLOAD` | An entry's `_v` is the wrong shape for its type |
| `CIRCULAR_REF` | A forged entry that refers to itself where no cycle is possible (e.g. a boxed `Number`) |
| `UNSUPPORTED_VALUE` | A symbol, function or class instance given to `stringify` |
| `TEMPORAL_UNAVAILABLE` | Temporal data, but no `globalThis.Temporal` |
| `INVALID_OPTION` | A limit that is not a non-negative integer or `Infinity` |

## API

| Export | Purpose |
| --- | --- |
| `stringify(value, options?)` | Any value → JSON text |
| `parse(text, options?)` | JSON text → value; validates everything it reads |
| `encode(roots, options?)` | Low level: encode several values that share one `$refs` table, to embed in your own JSON |
| `decode(values, refs, options?)` | Low level: the inverse of `encode` |
| `SerializeError` | The error class; see [Errors](#errors) |

`encode` / `decode` are how obj-diff writes each diff op as `{type, path, value, $refs}`:

```ts
const { values: [path, value], refs } = encode([op.path, op.value]);
const wire = JSON.stringify({ type: op.type, path, value, $refs: refs });

const raw = JSON.parse(wire);
const [p, v] = decode([raw.path, raw.value], raw.$refs, { maxDepth: 64 });
```
